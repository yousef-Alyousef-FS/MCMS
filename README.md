 # نظام إدارة مركز طبي

تطبيق Flutter لإدارة وتنظيم أعمال المركز الطبي، مع دعم تشغيل المشروع على أكثر من منصة.

## المتطلبات

- Flutter SDK
- Dart SDK
- Android Studio أو Visual Studio لتشغيل المنصة المطلوبة

## تشغيل المشروع

1. تحميل المشروع:

```bash
git clone <repository-url>
cd medical_center
```

2. تثبيت الحزم:

```bash
flutter pub get
```

3. تشغيل التطبيق:

```bash
flutter run
```

لتشغيل نسخة Windows:

```bash
flutter run -d windows
```

لتشغيل نسخة الويب:

```bash
flutter run -d chrome
```
